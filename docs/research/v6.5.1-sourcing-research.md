# OpenEVSE PLUS v6.5.1 – station sourcing research

Scope: v6.5.1 only. That means the 2-layer EAGLE design (`OpenEVSE_PLUS_v6.5.1/`) and the 6-layer KiCad design (`OpenEVSE_PLUS_v6.5.1_6Layer/`). The KiCad schematic carries the same values as EAGLE for every part flagged below. Board BOM: `docs/research/v6.5.1-board-bom.csv`, generated from the EAGLE `.sch`. Use the BOM `value` column, not `eagle_device`.

The v6.5 drawing (`OpenEVSE_PLUS_v6.5.1/OpenEVSE_v6.5.pdf`, DWG 20250310) covers the board only. Station-level items it does not show are taken from older drawings, and each such row is tagged:
- **[v5.5]** = `OpenEVSE_PLUS_v5.5/Advanced_2024.pdf`, which the official v6.5.1 build guide links in its step 1;
- **[v5]** = `OpenEVSE_PLUS_v5/*.pdf`.

Source keys in brackets resolve in section 4. Research date: 2026-10-25.
